# ISMP Mobile Application

Recovered React Native application with all navigation, screens, components, redux store, and native iOS/Android configurations.

### Project Structure
- `src/screens`: Auth, Onboarding, Profile, Map, Posts, Dashboard, Settings
- `src/components`: UI components, modals, dropdowns, tab bars
- `src/redux`: Redux slices (authSlice, profileSlice, store)
- `src/api`: Axios services and endpoints
- `src/navigation`: AppNavigator and navigation stacks
- `android`: Native Android configurations
- `ios`: Native iOS configurations
